# Sample advising data

`synthetic_requests.json` contains 18 entirely fictional advising requests with
hand-authored expected category and urgency labels. The file explicitly declares
`synthetic: true`, and all example identifiers start with `SYN-`.

These are test fixtures, not real student records or training data. They cover
the five routing categories, unknown and ambiguous requests, urgency levels,
blank input, capitalization, punctuation, and simple negated urgency.
